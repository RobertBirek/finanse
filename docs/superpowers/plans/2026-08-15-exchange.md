# Exchange (PLN↔EUR/USD) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a manual exchange transaction (PLN↔EUR/USD) with NBP or manual FX rate, recorded as a balanced `exchange` transaction.

**Architecture:** Backend adds a server-side `create_exchange_transaction` service + `POST /finance/transactions/exchange` endpoint that resolves the rate (manual or NBP via `NbpRateProvider`), computes both leg amounts with a shared `base_amount_pln` (sum zero), and delegates to `create_transaction`. Frontend adds `useCreateExchange` and an "exchange" type in `TransactionForm`.

**Tech Stack:** FastAPI, SQLAlchemy 2 async, httpx (NBP), React 18, TypeScript, TanStack Query v5, pytest, Vitest.

  Schema:
  ```python
  class ExchangeCreate(BaseModel):
      from_account_id: uuid.UUID
      to_account_id: uuid.UUID
      from_amount: int = Field(gt=0, description="Minor units of the from account currency")
      fx_rate: float | None = Field(default=None, gt=0)
      transaction_date: dt.date | None = None
      description: str = Field(min_length=1)
  ```

  Service (instantiate `NbpRateProvider`; import `_local_today`, `create_transaction`, `Account`, `PostingCreate`, `TransactionCreate`):
  ```python
  async def create_exchange_transaction(db, user_id, data: ExchangeCreate) -> FinancialTransaction:
      accounts = {a.id: a for a in await get_accounts(db, user_id)}
      from_acc = accounts.get(data.from_account_id)
      to_acc = accounts.get(data.to_account_id)
      if from_acc is None or to_acc is None:
          raise ValueError("Exchange account not found")
      if not from_acc.is_active or not to_acc.is_active:
          raise ValueError("Exchange accounts must be active")
      if from_acc.id == to_acc.id:
          raise ValueError("Exchange accounts must differ")
      from_cur = str(from_acc.currency).upper()
      to_cur = str(to_acc.currency).upper()
      if from_cur == to_cur:
          raise ValueError("Exchange accounts must have different currencies")
      if from_cur != "PLN" and to_cur != "PLN":
          raise ValueError("Cross-currency exchange is not supported")
      foreign_currency = from_cur if from_cur != "PLN" else to_cur
      effective_date = data.transaction_date or _local_today()
      rate_source = "manual"
      rate: float
      if data.fx_rate is not None:
          rate = data.fx_rate
      else:
          quote = await NbpRateProvider().get_rate(foreign_currency, effective_date)
          if quote is None:
              raise ValueError(f"No FX rate for {foreign_currency} on {effective_date}")
          rate = quote.rate
          rate_source = quote.source
      fx_rate_from = 1.0 if from_cur == "PLN" else rate
      fx_rate_to = 1.0 if to_cur == "PLN" else rate
      base = round(data.from_amount * fx_rate_from)
      to_amount = round(base / fx_rate_to)
      return await create_transaction(db, user_id, TransactionCreate(
          transaction_date=effective_date,
          description=data.description,
          type="exchange",
          postings=[
              PostingCreate(account_id=from_acc.id, source_amount=data.from_amount,
                            source_currency=from_cur, base_amount_pln=base,
                            fx_rate=fx_rate_from, fx_rate_source=rate_source, direction="debit"),
              PostingCreate(account_id=to_acc.id, source_amount=to_amount,
                            source_currency=to_cur, base_amount_pln=base,
                            fx_rate=fx_rate_to, fx_rate_source=rate_source, direction="credit"),
          ],
      ))
  ```

  Route (register BEFORE `GET /transactions/{transaction_id}` to avoid path capture):
  ```python
  @router.post("/transactions/exchange", response_model=TransactionResponse, status_code=status.HTTP_201_CREATED)
  async def create_exchange_endpoint(data: ExchangeCreate, current_user, db):
      try:
          return await create_exchange_transaction(db, current_user.id, data)
      except ValueError as e:
          raise HTTPException(status_code=status.HTTP_422_UNPROCESSABLE_ENTITY, detail=str(e))
  ```

    from_amount: number;

    description: string;

  export function useCreateExchange() {
    const queryClient = useQueryClient();
    return useMutation({
      mutationFn: async (input: ExchangeInput) => {
        const { data } = await api.post<Transaction>("/finance/transactions/exchange", input);
        return data;
      },
      onSuccess: () => invalidateFinanceLedger(queryClient),
    });
  }
