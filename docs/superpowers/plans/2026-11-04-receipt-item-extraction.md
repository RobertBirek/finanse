## Global Constraints

- „jednego wybranego, już dołączonego obrazu”: own active approvedreceiptPLN, one admittedJPEG/PNG/HEIF incl existing iPhonegainmap variant. NoPDF/textOCR/multipage/crops/newuploadautomation/historybatch.
- „Model interpretuje źródło, nie oblicza księgi”: no taxonomy/account/store/tools/SQL, no quantity×price/VAT/rounding/proportionaldiscountshares. Amounts exact safeBIGINT grosze; model-facing canonical decimal strings/null, neverfloat.
- „całego wybranego obrazu”: consent explicitly includes visible personal/header data; only metadata-free normalizedJPEG exported, `store=false`, backend-only destination/config, no retries/fallback.
- „dodatkowym płatnym wywołaniem”: no claim that old header read contains products. Separate purpose off by default, separateepoch/fingerprint; no change to header/advisor/3B activation.
- „Licznik transportu≤1 na jedną generację”: persistent dispatchmarker/quota BEFORE HTTP; uncertain postmarker terminalunknown, never autoresend/refund. Cancellation wins beforemarker→0HTTP/0paidreservations; aftermarker→409, never fake cancellation.
- „nowa intencja/generacja”: reread only after terminal prior job, separate exportpreview/consent; start-response recovery replays SAMEbody/key, statusGET never starts work.
- „nowy szkic4A”: explicit import, no silent merge; currentapproved/lastapply/header/ledger/allocations/original unchanged. Existing two financial confirmations remain necessary.
- „Nie dodawać bill→Document edge”: preserve source-first locking; all ownership/source/context checks fresh after locks. No DB transaction during file/CPU/HTTP.
- Historical extractions, lineage and receipts stay readable after tighter intake limits/policyoff. No overwrite/backfill/replay of old headerrevisions or changes to their shape/kinds.
- Nativeinline/TDD retained, one final independent whole-change review, one Critical/Important fixpass; no productcommits until required project gate if interfaces still move. Preserve worktree/branch and Velo/Q7dirty; no mainmerge/push/deploy/provideractivation/liveAPI.

## Review Focus

1. A request times out after durable dispatch, the worker restarts, and Redis redelivers: no second HTTP for that generation, unknown remains charged, and late output cannot become ready.
2. Two tabs start with different keys or both reread the same terminal job: one content generation, explicit fresh consent for the next; frozen command replay is not current UI state.
3. A line price already includes its discount, or output is completeJSON but missing rows: no double subtraction/silent omission; unresolved source warnings block approval even when totals happen to match.
4. Cancellation/disable/archive/source-reassignment races with reserve/import, including attach_source's Document→bill locks: serial result or409, no bill→Document cycle or lost manual revision.
5. A new extraction arrives while the user edits a draft, changes photo, refreshes auth or replaces session: no automatic overwrite/old-response adoption; exact unknown intent survives until explicit recovery/abandonment.
